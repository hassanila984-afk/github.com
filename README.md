# JARVIS — مساعد صوتي

صفحة مستقلة (`index.html`) بيها هولوگرام جارفس، تسمعك بالمايك، وترد بالصوت بالعربي أو الإنگليزي. وإذا سكتت تبقى تنتظر لحد ما تگول اسمه «جارفس».
تحتاج تنفتح كصفحة عادية (مو داخل claude.ai)، لأن claude.ai يمنع المايك داخل صفحاته.

جارفس يحچي ويا الذكاء الاصطناعي عن طريق Google Apps Script، وهذا يخلي المفتاح مخفي ومحفوظ عند Google وما يطلع بالصفحة أبد.

## 1. مفتاح مجاني من Google Gemini (بدون فلوس)
1. ادخل على https://aistudio.google.com/apikey بحساب Google مالتك.
2. اضغط **Create API key**، وانسخ المفتاح (يبدي بـ`AIza`).
3. ما يحتاج بطاقة ولا دفع. بس هذا الخيار المجاني إله حد يومي للاستخدام، وGoogle تگدر تستخدم المحادثات بالخطة المجانية حتى تحسّن خدماتها، فلا تحچي وياه بأشياء حساسة.

> (اختياري، مدفوع) إذا تريد Claude بدال Gemini: سوّي مفتاح من https://console.anthropic.com واشحن رصيد، وحطه بخاصية `ANTHROPIC_API_KEY` بدال `GEMINI_API_KEY`. إذا الاثنين موجودين، الـrelay يستخدم Gemini.

## 2. الـrelay بـGoogle Apps Script
1. ادخل على https://script.google.com واضغط **New project**.
2. امسح الكود الموجود، والصق محتوى الملف `relay/Code.gs`، واضغط حفظ.
3. من **Project Settings** (أيقونة الترس) ← **Script properties** ← **Add script property**، ضيف:
   - `GEMINI_API_KEY` = المفتاح اللي نسخته
   - `PASSCODE` = أي كلمة سر تختارها
   - (اختياري) `MODEL`: الافتراضي `gemini-flash-latest`. لا تضيفه إلا إذا تعرف شنو تريد.
4. اضغط **Deploy** ← **New deployment** ← اختار النوع **Web app**:
   - **Execute as:** Me
   - **Who has access:** Anyone
5. اضغط **Deploy**، واسمح بالصلاحيات، وانسخ **Web app URL** (ينتهي بـ`/exec`).

> كلمة السر هي اللي تمنع غيرك يستخدم رصيدك. لا تشاركها ويا أحد.

## 3. افتح جارفس
- شغّل GitHub Pages: من **Settings ← Pages ← Source: Deploy from a branch ← main ← / (root) ← Save**.
- بعدها افتح رابط الـPages اللي يطلع لك بنفس الصفحة (مثلاً `https://hassanila984-afk.github.io/<اسم المستودع>/`).
- أول مرة تطلع الإعدادات: الصق رابط الـrelay وكلمة السر، واكتب شوية عن نفسك وشغلك حتى جارفس يعرفك. اضغط **افحص الاتصال** وبعدها **حفظ**.
- اضغط «اضغط حتى يصحى جارفس»، واسمح للمايك. بعدها احچي عادي:
  - يرد بالصوت، وبعدين يرجع يسمعك بنفسه.
  - إذا سكتت حوالي دقيقة ينام. گول **«جارفس»** فيصحى.
  - گول «English» أو «عربي» حتى تغيّر لغة السماع.

## ملاحظات
- **المتصفح:** يشتغل على Chrome وEdge وSafari. Firefox ما يدعم سماع الصوت.
- **الصوت:** جارفس يختار أحسن صوت بجهازك. أقرب صوت لجارفس الفلم:
  - على الآيفون: نزّل **Daniel (Enhanced)** من الإعدادات ← تسهيلات الاستخدام ← المحتوى المنطوق ← الأصوات.
  - على الكمبيوتر: استخدم Edge واختار **Microsoft Ryan Online (Natural)**.
  - بعدها اختار الصوت من الإعدادات (أيقونة الترس) بالصفحة.
- **الحفظ:** المحادثة والإعدادات تنحفظ بنفس الجهاز والمتصفح فقط.
- **تعديل الكود:** إذا غيّرت `Code.gs`، لازم تسوي **Deploy ← Manage deployments ← Edit ← New version** حتى يطبق التعديل.

## صلاحيات جارفس (الإصدار 4)
- **بحث Google:** أخبار، أسعار، أماكن، توصيل، أوقات دوام، طقس.
- **موقعك:** المتصفح يطلب الإذن مرة وحدة، وبعدها يفهم «قريب مني».
- **التقويم:** يقرا مواعيدك، ويضيف مواعيد وتذكيرات بعد ما توافق.
- **Gmail:** يقرا ويلخص إيميلاتك، ويكتب مسودات ردود. ما يرسل أبد؛ أنت ترسلها من Gmail.
- **ذاكرة:** گول «تذكّر إن…» ويحفظها.

حتى تشتغل صلاحيات Gmail والتقويم:
1. الصق الكود الجديد من `relay/Code.gs` واحفظ.
2. من القائمة اللي جنب زر **تشغيل (Run)** اختار الدالة `authorize`، واضغط **تشغيل**، واسمح بالصلاحيات.
3. خلي `PASSCODE` بخصائص النص البرمجي **12 حرف أو أكثر**. بدون هذا، Gmail والتقويم يبقون مقفولين.
4. **نشر ← إدارة عمليات النشر ← ✏️ ← إصدار جديد ← نشر**.
5. افتح رابط الـ`/exec` وتأكد إنه يبين `"version":4` و`"account_tools":true`.

## تنزيله كتطبيق
- **الكمبيوتر (Chrome أو Edge):** أيقونة التنزيل بشريط العنوان ← **Install**.
- **أندرويد:** القائمة ⋮ ← **Add to Home screen / Install app**.
- **آيفون (Safari):** زر المشاركة ← **Add to Home Screen**.
